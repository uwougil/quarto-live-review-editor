# 複雑なテーブルの表示確認

## 1. 装飾の入れ子

| 記法 | 表示 |
|---|---|
| `***bi***` | ***bi*** |
| `**a *b* c**` | **a *b* c** |
| `**[t](https://example.com)**` | **[t](https://example.com)** |
| `[**b** t](https://example.com)` | [**b** t](https://example.com) |

## 2. アンダースコアと記号

| 記法 | 表示 |
|---|---|
| `_em_` と `__strong__` | _em_ and __strong__ |
| `**2 * 3**` | **2 * 3** |
| `a * b * c` | a * b * c |
| `\*not em\*` | \*not em\* |

## 3. コードとHTML

| 記法 | 表示 |
|---|---|
| 複数バッククォート | ``a`b`` |
| コード内の記法 | `**not bold**` |
| 改行タグ | 1行目<br>2行目 |
| 生タグ | <b>literal</b> |
| 記号 | 1 < 2 & 3 |

## 4. 列揃え

| 左 | 中央 | 右 |
|:---|:----:|----:|
| a | b | c |
| longer | longer | longer |

## 5. 行の過不足

| a | b | c |
|---|---|---|
| 1 |
| 1 | 2 | 3 | 4 |
| 1 |  | 3 |

## 6. リスト内のテーブル

- 重みづけ：
  | 行動 | 経験値 |
  |---|---:|
  | 配達1個 | **1pt** |
  | `bonus` | *2pt* |
